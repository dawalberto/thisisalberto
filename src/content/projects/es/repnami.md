## ¿Qué es RepNami?

RepNami permite crear rutinas, registrar series, pesos y repeticiones, y consultar el historial y los récords. Los datos se guardan en el dispositivo para poder entrenar sin conexión; la sincronización entre dispositivos es opcional.

La aplicación está construida con React y TypeScript. Usa Tailwind CSS para los estilos, Supabase para autenticación y sincronización, Zustand para el estado y tecnologías PWA para instalarla y usarla sin conexión. Vitest cubre sus pruebas.
